# 2026 年 9 月开发记录

## 2026-09-23 — 0.2.0 持续启用与递归调度

- 目标：实施用户批准的 0.2.0 方案，只在本地更新、重装和提交；没有远端同步。
- 基线：源目录原先没有 Git 历史；升级前确认与已安装 0.1.0 的 18 文件一致，再建立本地提交 `83079bc` 和标签 `v0.1.0`。提交作者使用命令级 Codex 身份，没有改全局 Git 配置。
- 决策：[ADR 0002](../architecture/adr/0002-session-routing.md) 将启用偏好和工作暂停分开；移除固定三个并发及默认禁止后代的策略，Root 按宿主容量分配整树名额。
- 改动：两个技能及 UI、17 项参考、高档配置与递归协调参考、中文说明、维护/回滚文档、变更记录、行为场景和结构检查脚本。
- 质量：真实多轮状态、主→子→孙递归、XHigh/Max 显式请求、原始材料独立复核和模拟摘要续接已完成；见 [分类验证记录](../releases/0.2.0-validation.md)。
- 限制：临时 CLI 模型调用被现有凭据的 HTTP 401 阻断；本地入口发现通过。实际宿主压缩未测试。
- 数据：合成文件保留原哈希，只读分析；没有数据库、生产服务、API 迁移或额外功能。
- 发布：官方 helper 刷新 0.2.0 缓存并重装；最终提交、缓存路径和配置不变检查由交付报告记录，源文档不自引用最终 SHA。
- 回滚：保留 `v0.1.0`；按维护说明在干净工作树中切换旧源码、刷新缓存并重装，不丢弃未提交成果。
